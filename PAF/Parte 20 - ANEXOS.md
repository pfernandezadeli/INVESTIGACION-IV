# ANEXOS

Los anexos del proyecto serán organizados y enumerados de acuerdo con la guía institucional. Se considerarán los siguientes documentos:

- Anexo 1: Acta de revisión de similitud de la investigación, cuando corresponda.
- Anexo 2: Registro digital de variables energéticas.
- Anexo 3: Ficha de análisis documental.
- Anexo 4: Bitácora técnica del sistema inteligente.
- Anexo 5: Matriz de evaluación de métricas del modelo.
- Anexo 6: Formato de consentimiento informado, si se recopila información de personas.
- Anexo 7: Evidencias de prueba piloto, configuración experimental o capturas del sistema.
- Anexo 8: Otros documentos técnicos pertinentes para la investigación.
