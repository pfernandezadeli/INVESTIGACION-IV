## 2.4. Técnicas e instrumentos de recolección de datos

### 2.4.1. Técnicas de recolección de datos

La recolección de datos en la presente investigación se realizará mediante técnicas cuantitativas orientadas a obtener información medible sobre el consumo energético en plantas agroindustriales de Lambayeque. Debido a que el estudio tiene un enfoque experimental, las técnicas seleccionadas permitirán registrar variables eléctricas, procesar datos energéticos y evaluar el desempeño del sistema inteligente basado en Machine Learning.

La principal técnica será la observación automatizada de datos energéticos, mediante la cual se recopilarán registros generados por sensores IoT, medidores inteligentes o fuentes digitales relacionadas con el consumo eléctrico de equipos agroindustriales. Esta técnica permitirá obtener información objetiva sobre variables como corriente, voltaje, potencia eléctrica, consumo energético, horarios de operación y comportamiento de equipos. Su aplicación es pertinente porque reduce la dependencia de registros manuales y facilita el análisis continuo de datos para la predicción y optimización energética.

También se utilizará el análisis documental y técnico, orientado a revisar registros energéticos, reportes operativos, hojas de control, especificaciones de equipos, históricos de consumo y documentos vinculados con la gestión energética de las plantas agroindustriales. Esta técnica permitirá complementar la información recolectada por el sistema y contextualizar el comportamiento energético observado durante la investigación.

De forma complementaria, se aplicará la experimentación computacional, ya que los datos recolectados serán utilizados para entrenar, probar y validar modelos de Machine Learning. Esta técnica permitirá comparar el desempeño de los modelos seleccionados mediante métricas cuantitativas, tales como error de predicción, precisión del modelo, tiempo de procesamiento y capacidad de identificar patrones de consumo energético.

### 2.4.2. Instrumentos de recolección de datos

Los instrumentos de recolección de datos estarán conformados por recursos tecnológicos y formatos estructurados que permitirán registrar, organizar y procesar la información necesaria para el desarrollo del sistema inteligente. Estos instrumentos serán utilizados para obtener datos válidos, objetivos y verificables, adecuados para el análisis cuantitativo y la validación experimental del sistema propuesto.

El primer instrumento será el registro digital de variables energéticas, compuesto por archivos estructurados en formatos como CSV, JSON o bases de datos, donde se almacenarán mediciones de corriente, voltaje, potencia eléctrica, consumo energético, fecha, hora y estado operativo de los equipos. Este instrumento permitirá disponer de datos organizados para el entrenamiento y evaluación de los modelos de Machine Learning.

El segundo instrumento será la bitácora técnica del sistema, en la cual se registrarán eventos de ejecución, errores, tiempos de procesamiento, resultados de predicción, parámetros del modelo y comportamiento del sistema durante las pruebas experimentales. Esta bitácora facilitará la trazabilidad del proceso de validación y permitirá comprobar el funcionamiento del sistema inteligente.

El tercer instrumento será la ficha de análisis documental, utilizada para organizar información proveniente de reportes energéticos, especificaciones técnicas de equipos, registros históricos de consumo y documentos operativos relacionados con la gestión energética. Esta ficha permitirá clasificar la información técnica relevante y vincularla con las variables consideradas en el estudio.

Finalmente, se utilizarán métricas de evaluación del modelo como instrumentos de medición del desempeño. Entre ellas se considerarán indicadores como el error absoluto medio, raíz del error cuadrático medio, coeficiente de determinación, tiempo de procesamiento y porcentaje de mejora en el consumo energético, según corresponda al modelo y a los datos disponibles. Estos instrumentos permitirán determinar si el sistema inteligente contribuye a mejorar la predicción y optimización del consumo energético en plantas agroindustriales de Lambayeque.

Los instrumentos serán validados mediante revisión técnica, coherencia con las variables de investigación y pruebas controladas de funcionamiento. Asimismo, su objetividad se garantizará mediante el uso de datos estructurados, registros automáticos y métricas cuantitativas reproducibles. Los formatos, fichas, bitácoras y configuraciones utilizadas durante la investigación podrán presentarse en los anexos del proyecto.
