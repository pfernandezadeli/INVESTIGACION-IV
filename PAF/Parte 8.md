## 1.7. Objetivos

### 1.7.1. Objetivo general

Implementar un Sistema Inteligente Basado en Machine Learning para la Predicción y Optimización del Consumo Energético en Plantas Agroindustriales de Lambayeque.

### 1.7.2. Objetivos específicos

- **OE1:** Identificar las variables energéticas que influyen en el consumo energético de las plantas agroindustriales de Lambayeque.
- **OE2:** Analizar el comportamiento del consumo energético mediante datos obtenidos a través de tecnologías IoT.
- **OE3:** Seleccionar modelos de Machine Learning para la predicción del consumo energético en plantas agroindustriales de Lambayeque.
- **OE4:** Aplicar Machine Learning para la optimización del consumo energético en plantas agroindustriales de Lambayeque.
- **OE5:** Validar el sistema inteligente para evidenciar la mejora de la eficiencia energética de las plantas agroindustriales de Lambayeque.
