# Reglas para citas y referencias

## Formato base

El formato base para citas y referencias será IEEE.

Las citas en el texto deben conservar la numeración entre corchetes usada por IEEE, pero con el ajuste institucional de agregar un código único antes del número.

Formato general:

`[CODIGO][Numero]`

En las referencias finales se mantendrá la estructura IEEE: autores, título, revista/conferencia/institución, volumen, número, páginas o artículo, año, DOI o enlace disponible.

El código único es un complemento interno de control y trazabilidad. No reemplaza los datos bibliográficos de la referencia IEEE.

## Código único de fuente

Cada cita y cada referencia deberá tener un código único e irrepetible antes del número de orden, con el siguiente formato:

`[CODIGO][Numero]`

Ejemplo:

`[S6X8][1]`

## Regla principal

El código identifica de forma fija a una fuente específica. Ese código no debe cambiar aunque el número de orden cambie.

El número de orden puede variar cuando se agreguen, eliminen o reordenen citas dentro del documento. Sin embargo, el código único debe permanecer asociado siempre a la misma fuente.

## Uso en citas

Una misma fuente puede citarse varias veces usando el mismo código.

Ejemplo:

`Según la Agencia Internacional de Energía, el sector industrial representa una parte significativa del consumo energético mundial [S6X8][1].`

Si luego entra una nueva cita antes de esa fuente, el número puede cambiar:

`Según la Agencia Internacional de Energía, el sector industrial representa una parte significativa del consumo energético mundial [S6X8][2].`

En este caso, el código `[S6X8]` se mantiene porque la fuente sigue siendo la misma.

## Uso en referencias

La referencia correspondiente debe incluir el mismo código único usado en la cita y mantener la estructura IEEE.

Ejemplo:

`[S6X8][1] International Energy Agency, "Industry - Energy System", 2023. [Online]. Available: https://www.iea.org/energy-system/industry.`

Si el orden de referencias cambia, solo cambia el número:

`[S6X8][2] International Energy Agency, "Industry - Energy System", 2023. [Online]. Available: https://www.iea.org/energy-system/industry.`

## Condiciones obligatorias

- Cada fuente debe tener un solo código único.
- No se debe reutilizar el mismo código para fuentes diferentes.
- Si una fuente se cita varias veces, se repite el mismo código.
- El código debe coincidir exactamente entre la cita en el texto y su referencia final.
- El número de orden puede actualizarse según la posición de la cita o referencia.
- Antes de agregar una nueva fuente, se debe verificar que su código no exista ya en el documento.
- La redacción de las referencias debe seguir el estilo IEEE usado en `Referencias.md`.
